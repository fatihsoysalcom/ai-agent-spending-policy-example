# AI Agent Spending Policy Example

This example demonstrates the critical distinction between an AI agent's technical ability to make payments and the necessity of a robust spending policy. It simulates an AI agent attempting to make various payments, which are then evaluated against a `SpendingPolicyManager` that enforces rules like daily limits, transaction limits, and approved vendors. The output clearly shows when a payment is approved or denied based on these predefined policies, highlighting the importance of governance over mere execution capability.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
